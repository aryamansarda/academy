# Academy website

Live site: https://aryamansarda.github.io/academy/

An independent copy of the personal website, including its Academy draft,
concepts, and assets. The original site at https://aryamansarda.github.io/
continues to be maintained separately.

GitHub Pages publishes the root of `main`. Keep `.nojekyll` and use relative
asset links. Run `python3 -m http.server 4173 --bind 127.0.0.1` to preview locally.
See [AGENTS.md](AGENTS.md) for editing and publishing conventions.

The tag `initial-copy-2026-10-25` preserves the exact original project files,
including the in-progress research popup edits. IEEE's paper preview awaits a
user-supplied PDF.
